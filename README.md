# Tera Elements

Static website for Tera Elements – handmade walnut serving boards.

Open `index.html` in a browser, or host the folder on any static host (e.g. GitHub Pages).

- `index.html` – the whole site (home, shop, product pages, cart, checkout, contact, about)
- `img/` – product photos, hero image and logo

Products are edited in the `PRODUCTS` list near the top of the `<script>` in `index.html`.
